# NewTab Product Context

## Register

Product.

## Users

NewTab is a personal browser extension for one primary user who opens it many times a day across an internal display and external monitors. The user values fast access to grouped links, predictable layout, and low-maintenance local-first data with optional WebDAV or GitHub Gist synchronization.

## Product Purpose

Replace the browser's default new-tab page with a quiet, dependable workspace: search first, frequently used links close at hand, and a compact management surface for organizing everything else.

## Brand Personality

Minimal, quiet, precise, and tool-like. The interface should feel considered without feeling decorated. Hierarchy comes from spacing, typography, and restrained tonal contrast.

## Anti-references

- “山寨” or template-like UI made from unrelated stock component defaults.
- Heavy full-width divider lines and boxed-in page chrome.
- One-off blue, orange, or other saturated accents that bypass the shared theme.
- Excessive cards, shadows, glass effects, or rounded containers used only for decoration.
- Layouts whose saved result changes merely because the browser moves between displays.
- Management UI that feels visually unrelated to the home screen.

## Design Principles

1. Prefer system-level tokens and shared primitives over per-screen overrides.
2. Use neutral color for ordinary actions and confirmations; reserve red for genuinely destructive or failed states.
3. Keep the home screen immersive and the management screen compact, but make both feel like the same product.
4. Use responsive constraints for available space while keeping persisted user layout independent of display resolution.
5. Make data ownership explicit: local-first behavior, safe export, and understandable synchronization conflicts.

## Accessibility

Maintain keyboard access and visible focus states for interactive controls, preserve readable contrast at WCAG AA level where practical, respect reduced-motion preferences, and never communicate destructive state through color alone.
